Getting an OpenAlex key

It is free and takes a couple of minutes.

  1. Make an account at openalex.org/signup and confirm the email address. A key only works once its address is verified.
  2. Copy the key from Settings → API key on openalex.org.
  3. Paste it here and save. Dovetail asks OpenAlex whether it works before keeping it, so a key that was mistyped or never activated is refused on the spot.

What it changes

  • A budget of your own: $1 a day, which is {{ '{:,}'.format(own_budget) }} credits, against the 1,000 a request with no key gets — and that anonymous allowance is shared by everything coming from the same address.
  • Dovetail can search for new journals. OpenAlex only allows that kind of search with a key.
  • What a consultation costs: 100 credits to classify the manuscript, up to about 40 to search for journals, and one per reference when you paste a reference list. The form shows the figure before you press the button.

The budget resets at midnight UTC. The key is stored encrypted and is never shown again, here or to whoever runs the server; you can revoke it at any time from the same page on openalex.org. Source: OpenAlex — Authentication, read on 20 Nov 2026.

Per person, not per machine. A model call bills the account of whoever started it, and this server holds no model credential of its own. The same goes for an OpenAlex key stored here: it pays for your consultations and nobody else's. Both are encrypted with Fernet, decrypted in memory when they are used, and never written to a log.

To remove a key, empty its field and save. A consultation itself needs no Anthropic key: only the two steps above do.
