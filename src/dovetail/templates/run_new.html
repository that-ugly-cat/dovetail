Every figure comes from the rate-limit headers OpenAlex returns, so this is arithmetic and not a guess — and it is a ceiling: the sweep stops early when the pool runs out, and the last two lines only happen if the grouping found journals the topic filter missed. A real run on 28 Aug 2026 spent 133 of these {{ estimate.total }}. The budget resets at midnight UTC.

Below {{ min_words }} words the classification is unstable — the same paper cut to one sentence comes back with topics disjoint from those of the full abstract — so Dovetail refuses rather than guesses. Above 2000 characters the API refuses instead, and the text is cut at a word boundary with the number of dropped characters recorded on the run.

With a reference list Dovetail also asks where the works you cite are themselves being cited, and lists those journals separately. It is the road to a journal that the topics cannot take: a paper about a technology is classified by the technology. References without a DOI — books, mostly — are not seen.
